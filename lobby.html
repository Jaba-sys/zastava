На телефон
Не задан адрес Realtime Database. В js/config.js пустое поле databaseURL. Если база уже создана — её адрес показан в консоли Firebase на вкладке Realtime Database → Data, над деревом данных. Если базы ещё нет: Build → Realtime Database → Create Database → регион europe-west1 → Start in locked mode, а правила взять из database.rules.json. Без адреса матч не запустится: по этой базе ходят позиции игроков.
