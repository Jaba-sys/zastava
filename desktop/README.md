# MyPeal Desktop

Тонкая desktop-обёртка (Electron) вокруг боевого сайта
[mypeal.web.app](https://mypeal.web.app). Код веб-приложения
не дублируется и не собирается заново — окно просто открывает тот же
production-сайт, поэтому оно всегда в актуальном состоянии, без отдельных
релизов при каждом обновлении сайта.

## Зачем это нужно

Веб-приложение уже умеет показывать системные уведомления о новых
сообщениях (см. `web/src/hooks/useMessageNotifications.js`) через обычный
браузерный Notification API — но только пока вкладка с сайтом жива. Обычно
человек рано или поздно закрывает вкладку/браузер, и уведомления пропадают.

Это приложение решает именно это: при клике на крестик окно не закрывается,
а сворачивается в системный трей и продолжает работать в фоне — точно так
же, как десктопный клиент Telegram. Тот же самый код показа уведомлений
продолжает работать, потому что вкладка (окно) технически не закрыта.

Это **не замена** email-уведомлениям (`web/src/utils/emailNotify.js`) — тот
канал специально нужен для случая, когда человека вообще нет за компьютером.
Здесь же — канал для случая, когда компьютер включён, но само окно/вкладка
были закрыты.

## Запуск в режиме разработки

```bash
cd desktop
npm install
npm start
```

## Сборка установщика

```bash
cd desktop
npm install
npm run dist:win     # установщик для Windows (.exe, NSIS)
npm run dist:mac     # .dmg для macOS
npm run dist:linux   # AppImage для Linux
```

Готовые файлы появятся в `desktop/dist-out/`.

## Что уже настроено

- **Значок в трее** с меню: открыть окно, переключатель автозапуска, выход.
- **Автозапуск при включении компьютера** — включён по умолчанию при первом
  запуске (можно выключить через меню трея в любой момент; выбор
  запоминается и больше не перезаписывается автоматически).
- **Одна копия приложения одновременно** — повторный запуск просто
  показывает и разворачивает уже открытое окно.
- Внешние ссылки (не на mypeal.web.app) открываются в обычном
  браузере, а не поверх окна приложения.
